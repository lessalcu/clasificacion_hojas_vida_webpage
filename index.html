Clasificación Automatizada de Hojas de Vida

Sistema web orientado a apoyar el proceso de evaluación, clasificación y preselección de hojas de vida mediante técnicas de procesamiento de texto y aprendizaje automático.

Ver documentación ↓ Ver proyecto en GitHub ↓
El proyecto

Una herramienta de apoyo para la evaluación de hojas de vida

La solución permite procesar hojas de vida en formato PDF, evaluar la información obtenida y generar una clasificación que facilite la revisión de candidatos dentro de un proceso de selección.

01

Procesamiento

Extracción y normalización de información proveniente de hojas de vida en formato PDF.

02

Clasificación

Aplicación de técnicas de aprendizaje automático para apoyar la clasificación de candidatos.

03

Ranking

Presentación ordenada de resultados para facilitar el análisis de los perfiles evaluados.

04

Trazabilidad

Registro de los procesos de evaluación realizados dentro del sistema.
